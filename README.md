## 📌 Project Overview
This project focuses on analyzing retail sales data from Blinkit to uncover key business insights.  
An interactive dashboard was built to track performance metrics such as total sales, average sales, number of items, and customer ratings.

---

## 🎯 Objectives
- Analyze overall sales performance and trends  
- Identify top-performing product categories and outlet types  
- Evaluate the impact of outlet size and location on sales  
- Provide actionable insights for business decision-making  

---

## 📂 Dataset Description
The dataset contains information about:
- Item types (Fruits, Snacks, Dairy, etc.)
- Fat content (Low Fat, Regular)
- Outlet size (Small, Medium, High)
- Outlet location tiers (Tier 1, Tier 2, Tier 3)
- Sales values and ratings

---

## 📊 Key KPIs
- 💰 Total Sales: **$1.20M**
- 📦 Number of Items: **8523**
- 📈 Average Sales: **$141**
- ⭐ Average Rating: **3.9**

---

## 📈 Dashboard Features
- Sales distribution by **Item Type**
- Analysis of **Fat Content impact on sales**
- Outlet performance by:
  - Size (Small, Medium, High)
  - Location (Tier 1, Tier 2, Tier 3)
- Trend analysis of outlet establishment over time
- Comparison of sales across different outlet types

---

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development & data visualization  
- **Microsoft Excel** – Data cleaning & preprocessing  
- **DAX** – Calculations and measures  

---

## 🔍 Key Insights
- Tier 3 outlets generated the highest sales compared to Tier 1 and Tier 2  
- Supermarket Type1 contributed the majority of total revenue  
- Regular fat products had slightly higher sales than low-fat items  
- Fruits & Snacks categories were top-performing segments  
- Medium-sized outlets showed balanced and consistent performance  

---

## 🚀 Outcomes
- Developed an interactive dashboard for quick decision-making  
- Enabled clear visualization of complex retail data  
- Provided actionable insights to improve sales strategy
